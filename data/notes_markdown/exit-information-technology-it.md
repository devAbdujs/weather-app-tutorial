Central Processing Unit (CPU): The primary component of a computer that acts as its "brain," performing arithmetic, logic, and control operations specified by instructions. 
 Control Unit (CU): The component of the CPU that directs the operation of the processor, telling the computer's memory, arithmetic/logic unit, and input/output devices how to respond to instructions. 
 Arithmetic Logic Unit (ALU): The part of the CPU that carries out all arithmetic (addition, subtraction) and logical (AND, OR, NOT) operations. 
 Registers: Small, high-speed storage locations within the CPU used to hold data immediately needed by the processor. 
 Cache Memory: A small, high-speed storage layer that sits between the CPU and RAM to store frequently accessed data for faster retrieval. 
 Random Access Memory (RAM): Volatile primary storage that holds the data and instructions currently being used by the computer; data is lost when power is removed. 
 Read-Only Memory (ROM): Non-volatile memory used to store permanent instructions like the BIOS; data remains even without power. 
 Bus: A communication system that transfers data between components inside a computer or between computers, consisting of data, address, and control lines. 
 Pipelining: A technique where multiple instructions are overlapped in execution, similar to an assembly line, to increase CPU throughput. 
 Clock Speed: The rate at which a processor executes instructions, typically measured in Gigahertz (GHz). 
 Instruction Set Architecture (ISA): The abstract model of a computer that defines the supported data types, registers, and the set of instructions the CPU can execute. 
 Motherboard: The main printed circuit board that connects all components of a computer, including the CPU, memory, and peripheral devices. 
 Graphics Processing Unit (GPU): A specialized processor designed to accelerate graphics rendering and handle parallel processing tasks (important for AI). 
 Solid State Drive (SSD): A storage device that uses flash memory to store data, offering much higher speeds and durability than traditional hard drives. 
 BIOS/UEFI: Firmware used to perform hardware initialization during the booting process and provide runtime services for operating systems. 
OSI Model: A conceptual framework consisting of seven layers (Physical to Application) used to understand and standardize network communication. 
 TCP/IP Suite: The standard conceptual model and set of communications protocols used on the Internet and similar computer networks. 
 Internet Protocol (IP) Address: A unique numerical label assigned to each device connected to a computer network that uses the Internet Protocol for communication. 
 IPv4: The fourth version of IP, using 32-bit addresses (e.g., 192.168.1.1), allowing for approximately 4.3 billion unique addresses. 
 IPv6: The successor to IPv4, using 128-bit addresses to provide a virtually unlimited pool of unique IP addresses. 
 Subnet Mask: A 32-bit number that masks an IP address and divides the IP address into network address and host address. 
 Router: A Layer 3 network device that forwards data packets between computer networks, determining the best path for data to travel. 
 Switch: A Layer 2 device that connects devices within a local area network (LAN) and uses MAC addresses to forward data only to the correct destination. 
 MAC Address: A unique hardware identifier assigned to a network interface controller (NIC) for use as a network address in communications within a network segment. 
 DNS (Domain Name System): The "phonebook of the internet" that translates human-readable domain names (google.com) into machine-readable IP addresses. 
 DHCP: A network management protocol used to dynamically assign IP addresses and other configuration parameters to devices on a network. 
 TCP (Transmission Control Protocol): A connection-oriented protocol that ensures reliable, ordered, and error-checked delivery of data. 
 UDP (User Datagram Protocol): A connectionless protocol that offers fast, "best-effort" delivery without guarantees of order or arrival (used for streaming/gaming). 
 HTTP/HTTPS: Protocols used for transferring web data; HTTPS includes an SSL/TLS layer for encryption and security. 
 Latency: The time delay between a request for data and the start of its transfer, often measured as "ping." 
 Bandwidth: The maximum rate of data transfer across a network path, usually measured in bits per second (bps). 
 VLAN (Virtual LAN): A logical grouping of network devices as if they were on the same LAN, regardless of their physical location. 
 Firewall: A security system that monitors and controls incoming and outgoing network traffic based on predetermined security rules. 
Relational Database (RDBMS): A type of database that stores data in tables with predefined relationships between them. 
 SQL (Structured Query Language): The standard programming language used to manage and manipulate relational databases. 
 NoSQL: A category of database management systems that do not use the traditional tabular relations (e.g., Document, Key-Value, Graph, Column-family). 
 Primary Key: A unique identifier for a record in a database table; it cannot contain null values. 
 Foreign Key: A field in one table that uniquely identifies a row in another table, used to establish relationships. 
 Normalization: The process of organizing data to minimize redundancy and prevent anomalies (1NF, 2NF, 3NF, BCNF). 
 ACID Properties: The set of properties (Atomicity, Consistency, Isolation, Durability) that guarantee database transactions are processed reliably. 
 Atomicity: The "all or nothing" principle ensuring that a transaction is either completely successful or completely rolled back. 
 Consistency: Ensures that a transaction brings the database from one valid state to another, maintaining all predefined rules. 
 Isolation: Ensures that concurrent execution of transactions leaves the database in the same state as if they were executed sequentially. 
 Durability: Guarantees that once a transaction has been committed, it will remain committed even in the case of a system failure. 
 Indexing: A data structure technique to quickly locate and access data in a database without having to search every row. 
 Transaction: A single logical unit of work that contains one or more SQL statements. 
 Deadlock: A situation in a database where two or more transactions are waiting for each other to release locks, preventing any from proceeding. 
 Stored Procedure: A prepared SQL code that you can save and reuse over and over again. 
Kernel: The core component of an OS that manages system resources and acts as a bridge between applications and hardware. 
 Process: A program in execution, consisting of the program code and its current activity. 
 Thread: The smallest unit of execution within a process; multiple threads in a process share the same memory space. 
 Scheduling: The process by which the OS decides which process runs on the CPU at any given time (e.g., Round Robin, First-Come First-Served). 
 Virtual Memory: A memory management technique that uses hardware and software to allow a computer to compensate for physical RAM shortages by temporarily transferring data from RAM to disk storage. 
 Paging: A memory management scheme that eliminates the need for contiguous allocation of physical memory by dividing memory into fixed-size pages. 
 Segmentation: A memory management technique where memory is divided into variable-sized segments based on logical groupings (like functions or arrays). 
 File System: The method and data structure that an OS uses to control how data is stored and retrieved (e.g., NTFS, FAT32, ext4). 
 Inode: A data structure in Unix-style file systems that describes a file-system object such as a file or a directory. 
 Interrupt: A signal to the processor emitted by hardware or software indicating an event that needs immediate attention. 
 GUI (Graphical User Interface): A type of user interface that allows users to interact with electronic devices through graphical icons and visual indicators. 
 CLI (Command Line Interface): A text-based interface used for entering commands to interact with the computer's OS. 
 Deadlock Prevention: Techniques used to ensure that at least one of the four necessary conditions for deadlock (Mutual Exclusion, Hold and Wait, No Preemption, Circular Wait) cannot occur. 
SDLC (Software Development Life Cycle): The process used by developers to design, develop, test, and deploy high-quality software. 
 Agile Methodology: An iterative approach to software development that emphasizes flexibility, continuous feedback, and rapid delivery. 
 Object-Oriented Programming (OOP): A programming paradigm based on the concept of "objects," which can contain data and code. 
 Encapsulation: The bundling of data and the methods that operate on that data within a single unit (class), hiding internal details. 
 Inheritance: A mechanism where a new class (subclass) acquires the properties and behaviors of an existing class (superclass). 
 Polymorphism: The ability of different objects to respond to the same function call in different ways. 
 Abstraction: The process of hiding complex implementation details and showing only the essential features of an object. 
 API (Application Programming Interface): A set of rules that allows different software entities to communicate with each other. 
 Version Control (Git): A system that records changes to a file or set of files over time so that you can recall specific versions later. 
 Unit Testing: A software testing method by which individual units of source code are tested to determine whether they are fit for use. 
 Refactoring: The process of restructuring existing computer code without changing its external behavior to improve non-functional attributes. 
 Technical Debt: The implied cost of additional rework caused by choosing an easy but limited solution now instead of a better long-term approach. 
 IDE (Integrated Development Environment): A software application that provides comprehensive facilities to computer programmers for software development (e.g., VS Code, IntelliJ). 
Encryption: The process of converting information into a secret code that hides the information's true meaning. 
 Symmetric Encryption: A type of encryption where only one key (a secret key) is used to both encrypt and decrypt electronic information. 
 Asymmetric Encryption: Also known as public-key cryptography, it uses a pair of related keys (public and private) for encryption and decryption. 
 Hashing: A one-way process of turning data into a fixed-length string of characters, used to verify data integrity and store passwords. 
 Phishing: A type of social engineering attack often used to steal user data, including login credentials and credit card numbers. 
 Malware: An umbrella term for any malicious software designed to disrupt, damage, or gain unauthorized access to a computer system. 
 Ransomware: A type of malware that threatens to publish the victim's data or perpetually block access to it unless a ransom is paid. 
 SQL Injection: A vulnerability where an attacker can interfere with the queries that an application makes to its database. 
 XSS (Cross-Site Scripting): A security vulnerability where an attacker injects malicious scripts into content from otherwise trusted websites. 
 Zero-Day Vulnerability: A software security flaw that is known to the software vendor but for which no patch or fix has been released. 
 Multi-Factor Authentication (MFA): A security system that requires more than one method of authentication from independent categories of credentials to verify the user's identity. 
 Penetration Testing: An authorized simulated cyberattack on a computer system, performed to evaluate the security of the system. 
 Social Engineering: The psychological manipulation of people into performing actions or divulging confidential information. 
 VPN (Virtual Private Network): A service that creates a safe, encrypted connection over a less secure network, such as the public internet. 
Cloud Computing: The on-demand availability of computer system resources, especially data storage and computing power, without direct active management by the user. 
 SaaS (Software as a Service): A software licensing and delivery model in which software is managed by the provider and accessed via a browser (e.g., Gmail). 
 PaaS (Platform as a Service): A cloud model that provides a framework for developers to build, test, and deploy applications (e.g., Heroku). 
 IaaS (Infrastructure as a Service): A cloud model providing virtualized computing resources over the internet (e.g., AWS EC2). 
 Elasticity: The ability of a cloud system to automatically scale its resources up or down in real-time based on demand. 
 Scalability: The capability of a system to handle a growing amount of work or its potential to be enlarged to accommodate that growth. 
 Virtualization: The act of creating a virtual version of something, including virtual computer hardware platforms, storage devices, and network resources. 
 Containerization (Docker): A lightweight form of virtualization that packages an application and its dependencies together in an isolated container. 
 Microservices: An architectural style that structures an application as a collection of small, autonomous services modeled around a business domain. 
 Edge Computing: A distributed computing paradigm that brings computation and data storage closer to the location where it is needed to improve response times and save bandwidth. 
 CAP Theorem: States that a distributed data store can only provide two of the three: Consistency, Availability, and Partition Tolerance. 
Artificial Intelligence (AI): The simulation of human intelligence processes by machines, especially computer systems. 
 Machine Learning (ML): A subset of AI that provides systems the ability to automatically learn and improve from experience without being explicitly programmed. 
 Supervised Learning: An ML approach where the model is trained on a labeled dataset (input-output pairs). 
 Unsupervised Learning: An ML approach where the model finds hidden patterns or intrinsic structures in input data without labels. 
 Deep Learning: A subset of machine learning based on artificial neural networks with multiple layers (hence "deep"). 
 Neural Network: A series of algorithms that endeavors to recognize underlying relationships in a set of data through a process that mimics the way the human brain operates. 
 Big Data: Extremely large data sets that may be analyzed computationally to reveal patterns, trends, and associations. 
 Blockchain: A decentralized, distributed, and oftentimes public, digital ledger that is used to record transactions across many computers. 
 IoT (Internet of Things): The network of physical objects embedded with sensors, software, and other technologies for the purpose of connecting and exchanging data with other devices. 
 Algorithm: A finite sequence of well-defined, computer-implementable instructions, typically to solve a class of specific problems or to perform a computation. 
 Data Mining: The process of discovering patterns in large data sets involving methods at the intersection of machine learning, statistics, and database systems. 
HTML (HyperText Markup Language): The standard markup language for documents designed to be displayed in a web browser. 
 CSS (Cascading Style Sheets): A style sheet language used for describing the presentation of a document written in a markup language like HTML. 
 JavaScript: A high-level, interpreted programming language that is one of the core technologies of the World Wide Web. 
 DOM (Document Object Model): A cross-platform and language-independent interface that treats an XML or HTML document as a tree structure. 
 Backend: The "server-side" of an application, consisting of the server, the application, and the database. 
 Frontend: The "client-side" of an application, which refers to everything the user sees and interacts with in the browser. 
 Full-Stack: Refers to a developer who is comfortable working with both back-end and front-end technologies. 
 Responsive Design: An approach to web design that makes web pages render well on a variety of devices and window or screen sizes. 
 JSON (JavaScript Object Notation): A lightweight data-interchange format that is easy for humans to read and write and easy for machines to parse and generate. 
 AJAX: A set of web development techniques using many web technologies on the client-side to create asynchronous web applications. 
Scope Creep: In project management, refers to changes, continuous or uncontrolled growth in a project's scope, at any point after the project begins. 
 SLA (Service Level Agreement): A commitment between a service provider and a client regarding the level of service (e.g., uptime) to be expected. 
 ITIL (Information Technology Infrastructure Library): A set of detailed practices for IT service management (ITSM) that focuses on aligning IT services with the needs of business. 
 DevOps: A set of practices that combines software development (Dev) and IT operations (Ops) to shorten the systems development life cycle. 
 Disaster Recovery (DR): A set of policies, tools, and procedures to enable the recovery or continuation of vital technology infrastructure and systems following a natural or human-induced disaster. 
 Business Continuity Planning (BCP): The process of creating systems of prevention and recovery to deal with potential threats to a company. 
 Change Management: A collective term for all approaches to prepare, support, and help individuals, teams, and organizations in making organizational change.
